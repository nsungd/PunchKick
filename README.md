# Punch + Kick
## State Machine
- Title Screen - START to go to Instructions
- Instructions - SELECT to go back to Title, START to continue game
- Stage 1 - START to pause, beat Dummy to advance
- Stage 2 - START to pause, beat Dummy to advance
- Stage 3 - START to pause, beat Dummy to win
- Pause - START to go back to game, SELECT to go back to Title
- Win - START to go back to Title

## Controls
Left - Move left
Right - Move right
Down - Crouch
Up - Jump
A - Punch
B - Kick
R Shoulder - Overhead 
L Shoulder - Super
Blocking - Holding back depending which direction your facing. Can be done while crouching

Cheat: Press select during gameplay to heal

## How to Play
You will fight 3 battles, each a best of 3. To win, beat all 3 fighters.
